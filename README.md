# minifider

Windows-приложение для пакетной обработки видео: сжатие, выравнивание громкости голоса и транскрипция речи в текст — всё в одном окне.

## Скачать готовое приложение

Ничего собирать не нужно — на странице [Releases](../../releases) лежит готовый архив `minifider-windows.zip`. Скачай последний релиз, распакуй архив в любую папку и запусти `minifider.exe` внутри неё (нужна вся папка целиком, не только `.exe`).

## Что умеет

Перетаскиваешь видео в окно (или выбираешь через диалог), отмечаешь галочками нужное и жмёшь «Начать обработку»:

- **Сжать видео** — пересжатие через ffmpeg с выбором пресета качества (высокое / среднее / низкое).
- **Выровнять громкость голоса** — фильтр (highpass + компрессор + нормализация), включается вместе со сжатием.
- **Транскрибировать** — распознавание речи в `.srt`/`.txt`. Основной способ — облачный Whisper от [Groq](https://console.groq.com/keys) (быстро, нужен бесплатный API-ключ, можно несколько — приложение само переключается между ними при исчерпании лимита). Локальная модель `faster-whisper` — полностью опциональный запасной вариант на случай, если Groq недоступен (включается отдельным флажком в настройках, по умолчанию выключен, т.к. требует скачивания модели в несколько гигабайт).

Оба действия независимы — можно только сжать, только транскрибировать, или оба сразу (тогда транскрипция идёт по уже сжатому файлу — быстрее, повторного декодирования оригинала не требуется).

## Настройка Groq API

При первом запуске (если ключей ещё нет) само откроется окно настроек. Получить бесплатный ключ: https://console.groq.com/keys — можно вставить несколько, по одному на строку. Ключи хранятся локально в `%APPDATA%\minifider\config.json`.

## Запуск из исходников

Нужен Python 3.11+ и [ffmpeg.exe](https://www.gyan.dev/ffmpeg/builds/) (для сборки/локального запуска положить в `assets/ffmpeg.exe` — сам бинарник не хранится в репозитории, он тяжёлый и не нужен просто для чтения кода).

```bash
pip install -r requirements.txt
python main.py
```

## Сборка `.exe`

```powershell
.\build.ps1
```

Результат — папка `dist\minifider\` (нужна целиком, это `--onedir`-сборка PyInstaller: внутри `minifider.exe` и `_internal\` со всеми зависимостями, включая `ffmpeg.exe` и локальную модель Whisper при необходимости).

## Заметки

- Язык распознавания речи — русский (`language="ru"`), задан в коде.
- Файлы длиннее ~1.5 часов могут не влезть в лимит Groq (25 МБ на файл после сжатия аудио) — тогда либо срабатывает локальный фоллбек (если включён), либо файл помечается ошибкой транскрипции; само сжатие видео при этом не страдает.
- Groq API: бесплатный тариф — до ~2000 запросов/день, при исчерпании лимита приложение либо ждёт его сброса (если локальный фоллбек выключен), либо переключается на локальную модель.
